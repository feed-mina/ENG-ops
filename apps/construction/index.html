건설현장 상담 초안

1. 대상과 가능한 일정

조공은 기술자 옆에서 자재 정리·운반을 돕는 인력입니다. 동반자는 각각 별도 상담이 필요하며, 원본의 인원 제한을 자동 탈락 규칙으로 쓰지 않습니다.

2. 참고 자료와 급여

참고 자료를 아직 적용하지 않았습니다.

월 총액·잔업 수당·실제 입금액을 자동 추정하지 않습니다. 28만 원은 모집 글의 숙련자 최대 금액입니다.

3. 현장 준비와 숙소

이수증·신분증·계좌번호를 업로드하거나 입력하지 않습니다. 연령·군필·신용 상태를 자동 탈락 조건으로 사용하지 않습니다.

4. 비용은 항목별로 확인

미확인과 무료는 다릅니다. 원본의 소개비나 공제 문구를 자동 승인하지 않습니다.

5. 가상 담당자 확인

입력값을 바꾸면 확인 체크가 해제됩니다. 실제 계약·근무 배정 기능은 포함되지 않습니다.
