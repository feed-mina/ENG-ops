# ops-web 내부 업무 화면 PoC

읽기 전용 SDUI 대시보드와 로컬 통화 업무 도우미를 검증하는 내부 전용 PoC입니다. 운영 빌드는 기본적으로 꺼져 있으며, 공개 사이트 배포물에는 포함하지 않습니다.

## 로컬 확인

```powershell
npm.cmd run dev:ops-web
```

그다음 `http://127.0.0.1:4175/`를 엽니다. 이 명령은 저장소의 Mock 문서와 Worker SDUI 로더를 재사용하는 로컬 합성 서버를 실행합니다. Cloudflare Access를 우회하거나 실제 계정·개인정보를 사용하지 않습니다.

`http://127.0.0.1:4175/#consultation`에서는 다음 흐름을 확인할 수 있습니다.

- 통화 참여자 동의 확인 후 브라우저 마이크로 녹음
- 클로바노트에서 녹음·전사하기 또는 VTT/SRT/TXT 자막 불러오기
- 구직자 상담 / 식당 사장님 구인 상담별 업무 프롬프트 만들기
- 상담 날짜와 선택 제목(미입력 시 날짜·상담 유형으로 자동 생성)을 포함한 업무 기록 초안
- 담당자 검토 후 텍스트 복사·다운로드
- 주민등록번호·전화번호·이메일·계좌·카드·인증정보의 명백한 패턴 마스킹
- 원문 검토와 민감정보 삭제 확인 후 프롬프트 복사

녹음·전사문·프롬프트는 서버, D1, R2로 전송하거나 저장하지 않습니다. 녹음 파일은 브라우저의 Blob URL로만 재생되며, 사용자가 명시적으로 저장할 때만 내려받습니다. 클로바노트에 남은 원본·녹취는 작업 후 해당 서비스에서 별도로 삭제해야 합니다.

일반 전화 앱의 통화기록을 자동으로 가져오지는 않으며, 브라우저 마이크에 들리는 소리만 녹음합니다. 자동 마스킹도 일부 번호·이메일·인증정보 패턴에 한정되므로 이름·주소·생년월일·건강·가족 정보는 담당자가 직접 삭제해야 합니다.

기본 빌드(`npm.cmd run build:ops-web`)는 SDUI 플래그가 꺼져 있어 API를 호출하지 않고 `/admin#dashboard` 대체 링크만 보여 줍니다. 로컬 합성 서버용 `dev:ops-web`만 명시적으로 플래그를 켭니다.

## 운영 전환 조건

- 별도 내부 경로에만 배포하고 Cloudflare Access 기본 거부 정책을 적용합니다.
- 마이크 권한은 내부 화면 origin에만 허용하고 카메라·위치 권한은 계속 차단합니다.
- owner/staff 실제 계정, 비활성 계정, 세션 만료를 staging에서 확인합니다.
- 실제 개인정보로 검증하지 말고, 합성 전사문으로 동의 차단·마스킹·복사 전 검토 절차를 확인합니다.
- 실패 또는 capability 불일치 시 일부 SDUI 화면을 남기지 않고 기존 `/admin#dashboard`로 복귀하는지 확인합니다.
- 실제 전환 후에도 기존 화면 경로를 유지해 기능 플래그를 끄는 즉시 롤백할 수 있어야 합니다.
