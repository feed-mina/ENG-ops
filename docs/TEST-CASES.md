- 계약 확인 전 소개요금 청구 차단
- 근로자·식당 Mock 소개요금 상한 검증
- 사업자 미확인·임금 미달·체불 검증 미완료 구인 차단
- 주민등록번호 형태와 신분증/건강 상세정보 문구 탐지
- 날짜·직종·지역·희망임금·보건증 상태 기반 후보 정렬
- 준법 기한 D-day와 위험도 계산

- 모든 Mock 문서의 `mock: true`와 경고문 확인
- 보안 응답 헤더 확인
- 사업자등록증·현장 실사·3개 업무 흐름 Mock 구조 확인
- 사용자 공개 승인과 원본 확인 상태가 구분되는지 확인
