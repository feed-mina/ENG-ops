# ADR 0001 — Mock 우선 정적 프로토타입

## 상태

승인됨 — 2026-07-15 개발 검증 단계에만 적용

## 결정

- 실제 등록증·보험증권·수첩·개인정보 대신 명시적으로 표시된 Mock JSON과 합성 데이터를 사용한다.
- 공개 홈페이지와 내부 운영 데모를 하나의 정적 애플리케이션에서 제공한다.
- 내부 화면에는 인증·영구저장이 없음을 고정 표시한다.
- 요금, 구인검증, 후보순위 규칙은 화면과 자동 테스트가 공유하는 순수 JavaScript 모듈로 구현한다.
- 배포 산출물은 외부 패키지 없이 Cloudflare Worker 호환 ESM으로 만든다.
- `.openai/hosting.json`의 D1·R2 바인딩은 Mock 단계에서 `null`로 유지한다.

## 이유

현장 원본과 법정 상태가 아직 확인되지 않았으므로 실제 자료를 디지털화하면 잘못된 정보와 개인정보가 시스템에 고착될 위험이 있다. 먼저 합성 데이터로 정보구조, 업무순서, 차단규칙, 화면 사용성을 검증한다.

## 운영 전 반드시 바꿀 것

1. 대표자와 동작구 확인 결과로 회사·법정 설정을 확정한다.
2. 관리자 인증과 역할별 서버 권한검사를 적용한다.
3. D1/PostgreSQL 계열 영구저장과 암호화, 마이그레이션을 도입한다.
4. 문서 저장은 R2 계열 암호화 저장소와 접근감사로 이전한다.
5. 변경 불가능한 감사로그, 백업·복구, 보존·파기를 구현한다.
6. 실제 개인정보 처리 전 개인정보 처리방침과 동의문을 검토한다.

## 금지사항

- Mock 화면에 실제 근로자나 식당 담당자 정보를 입력하지 않는다.
- Mock 문서를 실제 제출·보험·교육·점검 증빙으로 사용하지 않는다.
- 내부 데모 URL을 인증된 운영 시스템으로 오해해 공개하지 않는다.
