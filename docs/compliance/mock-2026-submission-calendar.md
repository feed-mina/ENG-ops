|---|---:|---|---|
| 상호·위치·대표자·종사자·겸업사항 변경 | 발생일부터 30일 | 변경등록 신청서와 변경 증빙 | `registrationChange` |
| 보증보험 갱신 | 갱신일부터 10일 | 갱신 증권과 제출 확인 | `insuranceRenewalEvidence` |

- 종사자명부, 구인접수대장, 구직접수·직업소개대장, 일용근로자 회원명부, 금전출납부는 Mock에서 완료일로부터 2년 만료일을 계산한다.
- 일용근로자 서식 면제 가능 여부와 무관하게 구인·구직·소개·금전 기록은 남긴다.
