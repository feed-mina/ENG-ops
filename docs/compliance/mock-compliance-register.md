## 현장 확인 후 교체 순서

1. Mock 등록증을 실제 등록사항에서 전사한 검증 레코드로 교체한다.
2. 보험 만료일과 교육수료일을 원본 대조 후 입력한다.
3. 사용자 공개 승인 전화와 원본 확인 상태를 구분하고, 운영시간을 현장에서 확인한다.
4. 수첩의 개인정보를 GitHub에 올리지 않고 가림 샘플로 필드만 대조한다.
5. 동작구 답변일·담당부서·답변 요지를 이슈 #4에 기록한다.
