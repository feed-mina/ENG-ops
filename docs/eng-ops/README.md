# ENG-ops 반영 결과와 Cloudflare 배포 안내

## 목적

전화 상담자가 매뉴얼과 광고의 서로 다른 조건을 구분하고, 다시 물어볼 내용을 빠뜨리지 않도록 돕습니다. 원본 mom 프로젝트는 유지하고 독립 저장소에서 보고서의 1~2단계를 구현합니다.

## 반영 내용

| 보고서 항목 | 구현 | 실제 동작 |
|---|---|---|
| 자료 3종 비교 | 구현 | A·B·C의 일급, 월급 기준 하루 단가, 지급일·비용을 나란히 표시 |
| 출처·버전 | 구현 | 자료 이름·원문 항목·기준 버전을 요약에 포함 |
| 조건 충돌 | 구현 | C의 당일/익일 충돌과 A·B의 숙식비 차이를 표시 |
| 상담 순서 | 구현 | 대상·일정 → 급여 → 현장 준비 → 항목별 비용 → 검토 |
| 미확인 처리 | 구현 | 미확인을 무료·증빙 확인으로 바꾸지 않음 |
| 검토·변경 | 구현 | 담당자 확인과 현재 버전 원문 대조 후 확인 요약 활성화. 수정하면 해제 |
| 요약·인쇄 | 구현 | 로컬 TXT 초안/가상 확인 요약 다운로드, 인쇄 대화상자 |
| 실제 접수 저장·배정·장부 | 범위 밖 | API는 DRAFT_ONLY로 차단. D1·서비스·외부 AI 미연결 |

가상 대상·현장만 선택할 수 있으며 이름·전화·계좌·신분증 입력 칸은 없습니다. 원본의 나이·군필·신용 상태 제한을 자동 배정 규칙으로 만들지 않았습니다. 동반 인원은 질문으로 기록하고 별도 상담 필요를 표시합니다.

## Cloudflare 배포 가능 여부

**이 가상 상담 화면은 Cloudflare Workers에 배포 가능한 구성입니다.** 새 `wrangler.jsonc`는 `eng-ops`만 대상으로 하며 기존 `harmony-ops-site`·`harmony-ops-staging` 바인딩을 사용하지 않습니다. 기존 식당 업무 모듈과 문서는 저장소에 보존하지만 ENG 배포에는 포함하지 않습니다.

Cloudflare Workers Builds는 Git 연결에서 빌드 명령과 배포 명령을 구분합니다. Wrangler의 build 설정은 직접 실행 시 빌드를 수행합니다. 아래 설정을 사용합니다.

1. Workers & Pages에서 새 Worker를 만들고 `feed-mina/ENG-ops` 저장소를 선택합니다.
2. 운영 브랜치를 `main`, 루트는 저장소 루트로 둡니다.
3. 빌드: `npm run build`.
4. 배포: `npx wrangler deploy --config wrangler.jsonc`.
5. Worker 이름은 `eng-ops`로 맞춥니다. 현재 앱용 환경변수·D1·R2·서비스 바인딩은 없습니다.
6. 생성된 주소에서 비교표 → 상담 초안 → 가상 예시 → 누락 확인 → 내려받기를 확인합니다.

실제 사용자 데이터를 저장하는 내부 시스템으로 전환할 때는 동의·권한·보관·감사·DB 설계가 추가로 필요합니다. 현재 공개 배포 가능하다는 결론은 **가상 데이터로만 작동하는 화면**에 대한 것입니다.

### 확인한 것과 미확인인 것

- 확인: 실행 소스 구조, 새 독립 설정, 가상 상담 검사, 배포 패키지 dry-run.
- 실제 계정의 새 Worker 생성·저장소 연결·권한·도메인·운영 접속: 이번 작업에서 실행하지 않음.
- 원본 코드의 운영 배포 여부와 ENG 배포 여부는 별개.

공식 근거(2026-10-29 조회):

- [Wrangler 사용자 빌드](https://developers.cloudflare.com/workers/wrangler/custom-builds/)
- [정적 자산과 Worker 바인딩](https://developers.cloudflare.com/workers/static-assets/binding/)

## 검증 결과

- 원본 회귀와 신규 상담 단위 검사: 193개 통과.
- 정적 소스 lint: 58개 파일 통과.
- 기존 P0 실제 데이터 운영 차단 설정 검사 통과.
- 실제 Chromium: 비교표, 가상 예시, 지급일·비용 미확인, 원문 대조, TXT 초안·확인 요약 내려받기, 수정 후 확인 해제, 새로고침 초기화 확인.
- 1280px·420px 가로 넘침 0, 페이지 JavaScript 오류 0, 상담 중 API 요청 0.
- ENG Cloudflare Wrangler dry-run: 정적 파일 4개와 ENG_ASSETS 바인딩만 포함. 로컬 실행은 복사한 런타임과 호환되는 날짜(2026-07-17)를 사용.

## 후속 개발

원문 기반 AI 보조, 실제 상담 저장, 건설 전용 업체·현장·배정 테이블, 장부 연결은 후속 단계입니다. 초기 화면은 저장·계약·급여 확정 없이 사용성을 확인하기 위한 시제품입니다.
