# 전화·방문 접수 및 양방향 안내 표준 (Mock)

> 사장님이 전화나 방문 상담 중 한 항목씩 묻고 내부 화면에 적는 순서다. 공개 홈페이지에서는 이 정보를 입력받지 않는다.

## 1. 일하실 분에게 받을 내용

1. 이름과 연락할 전화번호
2. 생년월일(18세 미만 여부와 장부 작성에 필요한 범위)
3. 해보신 일과 원하는 일
4. 일할 수 있는 날짜·시간·지역
5. 원하는 임금과 이동 방법
6. 식품을 다루는 일이라면 보건증 확인 여부·확인일·만료일
7. 외국인이라면 해당 일을 할 수 있는 체류자격 확인
8. 개인정보 수집·이용 동의와 식당에 필요한 정보를 알려주는 동의를 각각 확인
9. 긴급연락처 등 선택정보는 꼭 필요한 정보와 따로 묻고, 거절해도 기본 상담을 진행

받지 않는 것: 주민등록번호, 신분증 원본·사본, 보건증의 검사 상세내용.

## 2. 일하실 분에게 알려드릴 내용

- 식당 이름과 실제 일할 주소
- 하는 일, 근무 날짜·기간, 시작·종료·휴게시간
- 임금, 지급일, 지급방법
- 식사·교통·복장 제공 여부와 안전 주의사항
- 식당에 전달할 정보의 종류와 동의 철회 방법
- 소개 진행 상태와 소개요금이 있다면 계산 근거

소개 확정 전에는 조건을 다시 읽어드리고 양측 확인을 기록한다.

## 3. 식당에서 받을 내용

1. 상호, 대표자, 담당자, 전화, 사업장 주소
2. 사업자등록번호, 업종, 영업허가번호
3. 실제 근무지와 필요한 직종·인원·상세업무
4. 근무 날짜·기간, 시작·종료·휴게시간
5. 임금, 지급일, 지급방법
6. 식사·교통·유니폼 제공 여부와 안전 주의사항
7. 사업자·영업허가·체불·최저임금 확인에 필요한 사실

성별·나이는 기본 조건으로 받지 않는다. 법적으로 정당한 사유가 확인되는 예외만 사유와 함께 별도 검토한다.

## 4. 식당에 알려드릴 내용

- 소개소가 확인할 절차와 허위·최저임금 미달 조건은 진행할 수 없다는 점
- 후보에게 전달할 근로조건 요약
- 후보가 동의한 최소 정보만 전달한다는 점
- 소개 확정 여부와 요금 계산 근거
- 구인조건이 바뀌면 소개 전에 다시 알려야 한다는 점

## 5. 사장님용 통화 순서

```text
접수구분(전화/방문) → 상대방 확인 → 필수항목 질문 → 조건 다시 읽기
→ 동의/검증 확인 → 빠진 내용 표시 → 후보 연락 → 양측 최종 확인
→ 소개 상태 기록 → 계약 확인 뒤 요금 기록 → 보존기한 등록
```

내부 API는 식당 접수 후 근로자에게 읽어줄 `근로조건 요약`을 자동 생성하며, 사업자·허가·체불·최저임금 검증 중 하나라도 끝나지 않으면 차단 사유를 함께 표시한다.
