## 실데이터 운영 전 필수 게이트

1. 실제 등록 상태, 보험, 교육, 종사자 현황과 영업시간·휴무일을 원본으로 확인한다.
2. 전화·방문 상담 3건을 개인정보를 가린 메모로 관찰해 필드 누락을 고친다.
3. 개인정보 동의문·제공 범위·보존기간을 실제 운영 기준으로 승인한다.
4. Worker용 Cloudflare Access 기본 거부, 허용 사용자, MFA, production D1, 암호화·감사 키, 백업 복구를 실제 계정에서 검증한다.
5. 하루·1개월·회원제 사례를 실제 정보 없는 승인용 표본으로 PDF/Excel 내보내기까지 확인한다.
