# Mock 보안·복구 운영서

## 현재 단계

이 프로토타입에는 인증, 운영 데이터베이스, 파일 업로드, 외부 AI 호출이 없다. 화면 조작은 메모리에서만 유지되며 새로고침하면 초기화된다.

## 개발 중 안전수칙

- 실제 주민등록번호, 신분증, 전화번호, 보건증 원문을 저장소·이슈·Mock 화면에 넣지 않는다.
- 테스트 데이터 ID는 `MOCK-` 또는 `*-MOCK-*` 형식을 사용한다.
- 실제 문서가 필요하면 먼저 사본을 만들고 모든 식별정보를 가린 뒤 필드 구조만 참고한다.
- 비밀값과 운영 계정은 저장소에 커밋하지 않는다.

## 운영 전 보안 게이트

- 관리자 MFA 및 대표자·종사자·관리자 권한 분리
- API와 서버 작업별 권한검사
- DB·문서·백업의 전송 및 저장 암호화
- 조회·수정·내보내기·파기 감사로그 분리 보관
- 대량조회·야간접근·로그인 실패 탐지
- 백업 복구훈련과 RPO/RTO 기록
- 보존만료 데이터와 백업의 순차 파기
- 기기분실·계정탈취·오발송·유출 의심 대응 연락망

## Mock 복구

Mock 상태는 원본 소스에서 다시 생성한다. `npm test`가 통과하면 Mock 데이터와 규칙의 기준 상태가 복원된 것으로 본다. 실제 운영 복구 절차로 사용해서는 안 된다.
